# Loan Approval Data Analysis

## Project Overview
This project focuses on analysing loan application data using Python and Tableau to understand loan approval patterns.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Tableau

## Project Components
### 1. Python Analysis
- Data loading and inspection
- Data cleaning
- Missing value treatment
- Exploratory Data Analysis
- Data visualisation
- Analysis of loan approval patterns

### 2. Tableau Dashboard
- Interactive loan approval dashboard
- Loan status analysis
- Education-wise loan analysis
- Property area analysis
- Visual representation of insights

## Folder Structure
- Python_Analysis
- Tableau_Dashboard
- Dataset

## Conclusion
This project combines Python-based data analysis and Tableau dashboard development to explore loan approval patterns.
